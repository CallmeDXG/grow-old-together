二、核心玩法循环

模拟中国孩子从出生到高考（18岁）的成长。回合制结构，共 48个回合。

每回合流程

安排日程→ 挖脑洞小游戏→ 随机事件→ 面子对决→ 回合结算

核心张力

父母满意度 vs 孩子压力
学习提升满意度，但压力过高导致崩溃。玩家在两端走钢丝。
学习成绩 vs 兴趣特长
全力学习能上好大学，但可能错过独特的艺术/体育结局。
短期回报 vs 长期积累
娱乐减压立竿见影，但拖慢属性成长，影响最终结局。

三、系统详细拆解

3.1 属性系统

核心属性影响附加属性作用
智商学习效率、理科面子面子对决攻击力
情商社交、人际压力过高→崩溃事件
体魄体育、健康满意度零花钱和自由度
记忆力文科、知识魅力社交和恋爱
想象力艺术、创造

3.2 挖脑洞（核心小游戏）

  • 网格棋盘上散布不同颜色属性碎片（黄=智商，粉=情商，绿=体魄，蓝=记忆力，紫=想象力）
  • 点击碎片激活连锁，有限行动次数内最大化收益
  • 特殊碎片：悟性（解锁技能）、减压、道具
  • 每回合必做——保证交互节奏感

3.3 日程安排

每回合 6个行动槽位：学习(各科) / 才艺(钢琴/画画) / 娱乐(减压) / 体育 / 社交。高端活动需悟性解锁。

3.4 面子对决

回合制卡牌战。亲戚聚会时触发，双方出"成就牌"比面子值。日常积累的才艺/成绩转化为战斗卡牌。

3.5 社交 + 恋爱

14位可交往角色（7男7女），好感度系统，毕业前可告白，影响结局和下一代。

3.6 结局系统

100+种职业结局（院士→网红→快递员），需要不同属性组合达到阈值。高考分数+属性+技能综合判定。

3.7 代际传承（杀手锏）

通关后角色成为下一代家长。属性/声望传递给下一代起点，Roguelike式渐进解锁。多周目让更高结局逐渐可能。

四、玩家评价

玩家爱的

  • 文化共鸣——"太真实了"
  • 幽默讽刺——Steam标签: "Psychological Horror"
  • 高重玩性——100+结局+代际
  • 轻量碎片化——3-5小时/局
  • 情感共鸣——唤起童年回忆

玩家批评的

  • 后期重复——多周目循环枯燥
  • 随机性强——事件触发太随机
  • 挖脑洞疲劳——每回合强制做
  • 平衡性差——部分路线过强/弱
  • Bug——偶发优化问题

六、要做成这样，你需要做什么

阶段一：核心系统搭建（2-3个月）

  1. 改为回合制结构
    建议每回合=半年，共约100回合（18→68岁）。每回合固定流程：安排行动→小游戏→事件触发→数值结算。
  2. 设计核心小游戏
    中国式家长的"挖脑洞"保证每回合有交互感。建议方案：
    A)「工作效率」消除游戏（决定收入/晋升）
    B)「沟通博弈」对话小游戏（决定关系变化）
    C)「时间分配」拖拽排列（决定资源分配）
  3. 日程安排界面
    每回合6-8个时间槽：工作/副业/陪伴家人/社交/自我提升/休息。不同组合影响收入、关系、健康。
  4. 结局判定系统
    30-50种结局，YAML配置表管理，明确数值阈值条件。

阶段二：内容填充（4-6个月，最重）

  1. 事件池：500+条事件
    按阶段(婚前/新婚/育儿/中年/老年) × 情境(职场/家庭/社交)。每条含：触发条件、文本、2-4选项、数值后果。
  2. 对话脚本：10万字+
    所有事件对话、配偶反应、家人互动。这是最大工作量。
  3. NPC系统：8-12位角色
    配偶候选(4-6位) + 朋友(2-3位) + 同事(2-3位)，独立好感度和专属事件线。
  4. "面子对决"对标系统
    建议：「七大姑八大姨」过年聚会——被亲戚比较，拿出"人生成就牌"对决。

阶段三：美术与UI（2-4个月）

  1. 美术风格确定
    建议：写实偏插画风（适合成人婚恋题材）或像素风（成本低+怀旧）。需要：角色立绘(6-10种年龄变化) + 背景(15-20张) + UI素材。
  2. 核心UI界面
    主界面(状态总览+雷达图) / 日程安排(拖拽时间槽) / 事件对话(立绘+选项) / 关系面板 / 经济面板 / 小游戏 / 结局展示。

阶段四：平衡与测试（1-2个月）

  1. 数值平衡
    自动化测试跑几千次模拟，确认各结局可达性合理。
  2. 防重复性设计
    事件不重复出现、不同年龄段有新机制浮现、重大选择打破循环感。

阶段五：发布（1-2个月）

  1. 多平台：优先Steam+iOS+Android，华为需适配鸿蒙SDK。
  2. 本地化预留：文本外置、多语言支持。
  3. DLC规划：首发核心体验，后续增加新职业/城市/角色/事件包。

七、引擎决策

建议：Ren'Py 原型 → Unity 正式版。
中国式家长大量UI交互+小游戏+回合制，Unity 2D更合适。当前Ren'Py版本作为剧本验证原型（已完成✓），正式版用Unity重构获得更好的交互能力。Game Studios的49个Agent完全适用。

模块工作量瓶颈
核心系统代码2-3个月小游戏+日程系统
内容策划4-6个月500+事件、10万字剧本
美术资源2-4个月角色立绘、UI
数值平衡1-2个月自动化测试+调优
测试发布1-2个月多平台+商店审核
总计8-14个月内容是最大瓶颈

最终结论：中国式家长的成功 = 精准文化洞察 × 回合制成瘾循环 × 海量内容重玩性。《白头偕老》已有前两点雏形，下一步：升级为回合制养成、加入小游戏打断节奏、用AI Agent批量生成事件池。
